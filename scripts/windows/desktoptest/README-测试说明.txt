nagare Windows 桌面窗口 · 测试包
=====================================

这是 nagare 的「测试构建」：在 nagare 自己的窗口里播放（WebView2 网页 + 挂进窗口的 mpv）。
它用一个全新的临时配置目录，不碰你自己装的 nagare 的配置，也不登录 animego。
全部跑完大约 5 分钟（自动 3–4 分钟 + 手动检查）。跑完把桌面上的两个 zip 发回来就行。


一、准备
--------
1. 先退出你自己装的 nagare（如果开着）：右键任务栏右下角的 nagare 托盘图标 → 退出 nagare。
2. 把整个测试包解压到一个文件夹（右键 zip → 全部解压缩），例如「桌面\nagare-wintest」。
   不要在 zip 里直接双击运行。
3. 外接屏可以接着（顺便测缩放），也可以不接。
4. 关掉或最小化不想被拍到的窗口（聊天、邮件、密码管理器之类）：测试会截整个屏幕的图放进报告。


二、自动测试（3–4 分钟，期间不要碰鼠标键盘）
--------------------------------------------
1. 双击 run-test.cmd。
   · 如果弹出「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。
   · 如果提示这台电脑没有 WebView2 运行时：按回车让它装（微软官方安装器，要联网）。
     这一步本身也是在测安装包里那个安装器，装上装不上都会记进报告。
2. 它会自己：打开 nagare 的窗口 → 加测试片 → 在窗口里播放 → 移鼠标、按空格、点右键菜单、
   双击全屏、Esc、最大化 / 最小化、置顶、Shift+N 下一集、Esc 返回媒体库、关窗口、再启动一次 → 退出，
   最后再假装「没有 WebView2」起一次，看是不是退回浏览器模式（这一次 mpv 会单独开一个窗口，是正常的）。
   每一步都会截图。窗口会自己动、自己全屏，这是测试在操作，不用管。
   · 测试不会起磁力（BT），按理不会弹「Windows 安全中心 / 防火墙」的对话框；万一弹了，点「取消」
     （别点「允许」：那会给测试版留下一条永久的防火墙规则）。
   · 测试注入按键前会确认前台是 nagare 的窗口；别的程序抢走焦点时那一步会跳过并记成失败，不会按到别的程序里。
3. 跑完后黑色窗口里会显示「通过 N 项，失败 M 项」，桌面上多出 nagare-wintest-report.zip。
   有失败也没关系，报告里有截图和日志，按回车关掉黑色窗口。


三、手动检查（自动测试做不到的几项，约 2 分钟）
------------------------------------------------
1. 双击 run-manual.cmd：nagare 会起来，测试片已经在媒体库里。
2. 在 nagare 的窗口里点开一集，然后逐项试下面这些，把结果（正常 / 不正常 + 一句话）写进
   「手动检查记录.txt」并保存（记事本打开就能写）：

   [ ] 1. 用鼠标拖标题栏移动窗口；拖窗口边缘改大小 —— 画面跟着变，没有黑边错位、没有闪烁残影。
   [ ] 2. 播放中按住进度条拖动，松开后跳到新位置；鼠标停在进度条上能看到缩略图。
   [ ] 3. 鼠标在画面上停 1 秒，光标自动隐藏，控制条淡出；一动鼠标又出来。
   [ ] 4. 按 Alt+Tab 切到别的程序，再切回 nagare：空格（暂停）、← →（快退快进）、↑ ↓（音量）还管用。
   [ ] 5. 滚轮调音量；双击画面全屏、Esc 退出全屏；Enter 全屏。
   [ ] 6. 标题栏右上角的 最小化 / 最大化 / 关闭（关闭 = 停止播放、窗口收起，nagare 留在托盘）。
   [ ] 7. 左键点托盘图标能重新打开窗口；右键托盘菜单里「在浏览器中打开」能用。
   [ ] 8. （有外接屏时）把窗口从笔记本屏幕拖到外接屏，再拖回来：界面和控制条大小正常、不模糊。
   [ ] 9. （键盘有媒体键时）播放 / 暂停、下一曲。
   [ ] 10. 在网页的搜索框里用中文输入法打几个字。
   [ ] 11. 播放中右键 → 菜单里点「返回 · Esc」，回到媒体库。
   （「nagare 开着时再启动一次，已有的窗口到前面」由自动测试做，别手动双击测试包里的 nagare.exe：不经脚本
     直接双击，它会用你自己的配置目录起一个新的 nagare。）

3. 全部试完后，回到黑色窗口按回车。桌面上会多出 nagare-wintest-manual.zip。


四、（可选）没有 WebView2 的真实场景
------------------------------------
自动测试已经模拟过一次。想在真机上试：设置 → 应用 → 找「Microsoft Edge WebView2 Runtime」，
如果能卸载就卸载，然后双击 run-manual.cmd：nagare 应该在浏览器里打开界面，播放时 mpv 单独开窗口，
设置页「播放器」一栏写着原因。试完再跑一次 run-test.cmd，它会提示把运行时装回去。
Windows 11 和大多数 Windows 10 不让卸载它，那就跳过这一项。


五、要发回来的东西
------------------
桌面上的 nagare-wintest-report.zip 和 nagare-wintest-manual.zip（日志里的登录凭证已经抹掉）。
测试用的临时目录在 %TEMP%\nagare-wintest-日期 下，跑完（或者中途关掉黑色窗口）会自己清掉：起过的 nagare
连同 mpv 一起结束，临时目录删除。


六、许可证
----------
nagare\mpv\ 里是 shinchiro/mpv-winbuild-cmake 构建的 mpv（GPLv3），与 nagare 的 Windows 安装包里的是同一份。
构建脚本与组件清单见 nagare 仓库的 THIRD_PARTY_NOTICES.md 与 scripts/windows/mpv.lock；完整对应源码
（mpv-winbuild-cmake 的源码快照）随每个 nagare 正式版的 GitHub Release 一起发布。这个测试包只给测试用，几天后会自动过期删除。
